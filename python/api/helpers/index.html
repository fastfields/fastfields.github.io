fastfields.helpers

Shared enums and argument-normalisation helpers for the fastfields packages.

The fastfields.numpy / fastfields.torch / fastfields.cupy wrappers and the fastfields.auto dispatcher all need the same backend-agnostic logic: the :class:Spline / :class:Bound enums, the order/bound normalisers, and the resolution of factor/shape/anchor into the per-dim scale + scalar shift that the resize binding consumes. It lives here, in one dependency-free package, so each consumer imports it instead of carrying its own copy.

This package is pure Python and dependency-free -- it imports nothing but the standard library, and in particular no numpy/torch/cupy and none of the compiled fastfields.dlpack bindings. That is the point of it existing separately: a fix to any of this logic ships as an ordinary pure-Python release, with no recompilation of the C++/CUDA chain and no per-platform wheel cycle.

fastfields.helpers is a sibling of fastfields.dlpack, not a layer over it -- neither package depends on the other.

is_cuda_backend 

is_cuda_backend(backend: Optional[str]) -> bool

Return whether backend names a CUDA build of fastfields-dlpack.

Parameters:

Name Type Description Default
backend str or None

A compute-backend label as exposed by fastfields.dlpack.backend: "cpu", "cu126", ... or None when the installed build carries no label (an unversioned source checkout).

 required

Returns:

Type Description
bool

True for cu<digits>, False for anything else -- None included. None means unknown, not CPU, so callers that reject a non-CUDA build should test backend is not None and not is_cuda_backend(backend) rather than negating this directly: a source build is unverifiable, and refusing it would block GPU development from a checkout for no safety gain.

cuda_backend_message 

cuda_backend_message(namespace: str, backend: Optional[str], because: str) -> str

Build the "this needs a CUDA build of fastfields-dlpack" message.

Shared by :mod:fastfields.cupy (which refuses at import) and :mod:fastfields.torch (which refuses only when a CUDA tensor meets a CPU-only build) so that one wording, naming both the index URL and the command that fixes it, covers both.

Parameters:

Name Type Description Default
namespace str

The importing namespace, e.g. "fastfields.cupy".

 required
backend str or None

The installed fastfields.dlpack.backend.

 required
because str

A clause completing "... cannot work because ...", stating what in the caller's situation requires CUDA kernels.

 required

Returns:

Type Description
str

The full multi-line message.

as_spline(value: int | str | Spline) -> int

Normalise a spline-order argument to an int in 0..7.

Accepts an integer, a :class:Spline enum, or a friendly string alias (e.g. "cubic"). Raises ValueError for an unknown alias or an out-of-range integer.

as_bound 

as_bound(value: int | str | Bound) -> int

Normalise a boundary-condition argument to an int in 0..7.

Accepts an integer, a :class:Bound enum, or a friendly string alias (e.g. "dct2", "wrap"). Raises ValueError for an unknown alias or an out-of-range integer.

normalize_shape 

normalize_shape(shape: int | Sequence[int], ndim: int) -> list[int]

Normalise a shape argument to a list of int of length ndim.

A scalar int is broadcast to ndim entries. Raises ValueError if an explicit sequence does not have length ndim.

infer_ndim 

infer_ndim(ndim: Optional[int], factor: float | Sequence[float] | None, shape: int | Sequence[int] | None) -> int

Infer the number of trailing spatial dimensions to resize.

An explicit ndim wins; otherwise a sequence shape or factor implies its length; failing that, 1.

check_ndim 

check_ndim(ndim: int, arr_ndim: int) -> None

Validate that ndim is in 1..arr_ndim (else ValueError).

resolve_out_spatial 

resolve_out_spatial(spatial_in: Sequence[int], ndim: int, factor: float | Sequence[float] | None, shape: int | Sequence[int] | None) -> tuple[int, ...]

Resolve the output spatial shape from factor or shape.

factor and shape are mutually exclusive; with neither, the output keeps the input spatial shape (identity). A scalar factor is broadcast to ndim entries; each output size is max(1, round(in * factor)).

anchor_scale_shift 

anchor_scale_shift(anchor: str, inshape: Sequence[int], outshape: Sequence[int], ndim: int) -> tuple[list[float], float]

Map a torch-interpol anchor to a per-dim scale and scalar shift.

The fastfields resize kernel samples input coordinate scale[d] * loc + shift * (scale[d] - 1) for output index loc. The four anchors of interpol.resize map onto (scale, shift) as:

========== ================= ======= anchor scale[d] shift ========== ================= ======= centers (in-1)/(out-1) 0.0 edges in/out 0.5 first in/out 0.0 last in/out 1.0 ========== ================= =======

Parameters:

Name Type Description Default
anchor str

Anchor name or abbreviation (centers/edges/first/last or c/e/f/l); matched case-insensitively on the first letter.

 required
inshape sequence of int

Input and output spatial sizes (length ndim).

 required
outshape sequence of int

Input and output spatial sizes (length ndim).

 required
ndim int

Number of spatial dimensions.

 required

Returns:

Name Type Description
scale list of float

Per-dim input-index step per output-index step.
shift float

Scalar sampling shift shared across dimensions.

Raises:

Type Description
ValueError

If anchor is empty or its first letter is not one of c/e/f/l.
